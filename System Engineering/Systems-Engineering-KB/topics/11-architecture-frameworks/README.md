# Architecture Frameworks: TOGAF, Zachman, NIST

> Domain: Design & Architecture · Learning order: 11 · Bloom target: Apply

## Overview

Three named enterprise-architecture frameworks dominate practice, and they are *not* the same kind of thing. **TOGAF** is a process/method — its Architecture Development Method (ADM) is a nine-phase cycle that tells you *how* to build and govern an architecture (source: m3-togaf). **Zachman** is a classification taxonomy — a 6×6 matrix that tells you *what* to document and *from whose viewpoint*, without prescribing any process (source: m3-zachman). **NIST** is a layered model — five interconnected layers (Business, Information, Information Systems, Data, Technology) that describe an enterprise from business goals down to hardware (source: m3-nist). This topic is about *applying* these three frameworks; the general idea of "what an architecture framework provides" and "architecture vs design" lives in [10-design-architecture-fundamentals](../10-design-architecture-fundamentals/README.md), and how to *choose* between options belongs to [12-design-tradeoffs](../12-design-tradeoffs/README.md) / [13-decision-matrix](../13-decision-matrix/README.md).

**What you already know that connects here:** [10-design-architecture-fundamentals](../10-design-architecture-fundamentals/README.md) defines an architectural framework as a structured approach with principles, views, and standards — this topic instantiates that definition in three concrete, named frameworks.

## Learning objectives

After this topic you will be able to:

- (Apply) Walk a system through all nine TOGAF ADM phases (Preliminary, A–H) plus central Requirements Management, naming each phase's purpose and a deliverable.
- (Apply) Populate cells of a Zachman 6×6 matrix for a given system (e.g. the "What" column across all six perspectives).
- (Apply) Map a system's concerns onto the five NIST EA layers.
- (Analyze) Compare TOGAF, Zachman, and NIST by *type* — process/method vs taxonomy vs layered model — and pick the right one for a stated need.
- (Apply) Identify which TOGAF artifact type (catalog, matrix, diagram) documents a given architectural fact.
