# Stages of the SE Process

> Domain: SE Foundations · Learning order: 2 · Bloom target: Understand

## Overview

Every system passes through the same ordered set of life-cycle **stages** — Concept → Development → Production → Operations & maintenance → Disposal — that carry it from a first idea to retirement (source: m1-stages). Each stage has a distinct goal and a distinct output that feeds the next one, so naming the stage tells you what work is happening and what should already be done. Stages are the *what* (the phases a system passes through); **lifecycle models** (Waterfall, V-Model, Spiral, Agile) are the *how* — they decide the order, overlap, and iteration of the work across these stages, and are covered separately in [03-lifecycle-models](../03-lifecycle-models/README.md).

**What you already know that connects here:** [01-se-fundamentals](../01-se-fundamentals/README.md) defines systems engineering as a structured approach managing a system across its whole life cycle; this topic names and explains the five stages of that life cycle.

## Learning objectives

After this topic you will be able to:

- (Understand) List the five stages of the SE process in order and state each one's goal (source: m1-stages).
- (Understand) Explain the purpose and main activities of the Concept, Development, Production, Operations & maintenance, and Disposal stages (source: m1-stages).
- (Understand) Classify a given engineering activity (e.g. feasibility study, factory acceptance testing, decommissioning) into its correct stage (source: m1-stages).
- (Understand) Explain how the output of one stage becomes the input to the next (source: m1-stages).
- (Understand) Walk through all five stages for a single example system, such as a satellite (source: m1-stages).
- (Understand) Distinguish life-cycle stages (what phases) from life-cycle models (how the work is sequenced) (source: m1-stages, m1-lifecycle).
