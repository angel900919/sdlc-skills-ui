# Strategy — anti-patterns (scan the draft before writing)

Each row is a rejection class. If the draft shows the symptom, fix it before writing the artifacts.

| Symptom | Why it fails | Fix |
| :-- | :-- | :-- |
| "Strategy" is a list of goals or values | No diagnosis — aspirations dressed as strategy | Name the one obstacle (Phase 2), then the policy + actions that beat it. |
| Vision and strategy are the same paragraph | A poster slogan labelled "strategy" | Separate them: vision = the future; strategy = the hard choices that get there. |
| OKRs written *as* the strategy | Skipped the diagnosis, jumped to metrics | OKRs **measure** the strategy; write the kernel first, derive OKRs last. |
| Vanity North Star (DAU, sign-ups, raw revenue) | Picked an easy-to-move number, not realised value | Choose a value-exchange metric that can't rise while customers churn; add a guardrail. |
| No non-goals — tries to do everything | Avoided the trade-off conversation | Force ≥1 explicit decline (segment / problem / channel / model). |
| Output-counting key results ("ship 5 features") | Feature-factory reflex; output over outcome | Restate each KR as an outcome that moved, from X to Y by a date. |
| Invented market size or customer claim in the diagnosis | Answered an external question from the room | Mark it `TODO:` / an assumption; route to `/market-research` (market) or `/discovery` (customer). |
| Strategy silent on how customers find it | Building is cheap; adoption is the bottleneck | Add a one-line distribution thesis; flag for `/market-research` if evidence-light. |
| Responsible-product floor skipped because "it's just a prototype" | The floor is non-negotiable at every tier | Answer the harm/exclude/leak question and set North Star guardrails before writing. |
| AI-drafted strategy pasted in without the user owning the call | Abdicating the bet to the model | The AI drafts; the human owns the diagnosis, the non-goals, and the bet. |
