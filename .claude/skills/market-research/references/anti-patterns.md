# Market research — anti-patterns (scan the draft before writing)

Each row is a rejection class. If the draft shows the symptom, fix it before writing the artifacts.

| Symptom | Why it fails | Fix |
| :-- | :-- | :-- |
| "We'll capture 1% of a $50 B TAM." | Top-down-only, TAM-as-forecast | Size bottom-up (reach × win-rate); reconcile to top-down; defend the SOM. |
| Market defined as "the X category." | Supply-side / category framing | Redefine demand-side by buyer + functional job; loop to `/discovery` if the job is unclear. |
| Sized one method only. | No triangulation — a wish, not a number | Size **both** ways, reconcile within ~15%, explain the gap. |
| Status quo / do-nothing missing from alternatives. | Only direct rivals counted (~40% of B2B losses are no-decision) | List the status quo first, then direct / indirect / non-consumption. |
| Phantom competitors listed. | Rivals no buyer actually evaluates | Keep only alternatives a real buyer considers. |
| Battlecards scraped from competitor websites. | CI as a filing exercise, not a decision tool | Make win/loss the backbone; tie each card to a decision; at prototype, flag desk-only honestly. |
| Loss reasons taken from the CRM field. | The seller's story (~85% wrong), not the buyer's | Interview won/lost buyers; reconcile buyer vs seller view. |
| Positioning starts from the category we want. | Tagline-first, aspiration-led | Run the Dunford order: alternatives → attributes → value → segment → category. |
| AI-surfaced trend taken as fact. | Output treated as truth, not draft | Human-validate each signal; record precision/horizon; cite the source. |
| Invented market size, cost, or quote. | Answered an external question from the room | Mark it `TODO:` with an owner, or a flagged assumption; route to `/research-report`. |
| One precise multi-year market forecast. | False precision on an uncertain bet | Size to rank the bet, not forecast it; state assumptions and revisit as evidence arrives. |
