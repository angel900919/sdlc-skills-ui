# .human/ — Documentation for People

**Narrative-first, plain English.** Where [`.ai/`](../.ai/) is the terse memory system an agent reads to *act*, `.human/` is where a person builds a *mental model*: how the system fits together, how to get started, why decisions were made, and what to do when things break. Same facts as `.ai/`, a different altitude — and `.ai/` is authoritative when they overlap (see [`../CONVENTIONS.md`](../CONVENTIONS.md) §3).

| Doc | Purpose |
|---|---|
| `architecture.md` | The system explained with a **Mermaid diagram** + prose |
| `onboarding.md` | Get a new developer productive in a day |
| `features/` | One narrative doc per feature (use `_template.md`) |
| `adr/` | Architecture Decision Records — the human-facing *why* (use `_template.md`) |
| `troubleshooting.md` | Symptom → cause → fix |
| `runbooks/` | One page per operational task (use `_template.md`) |

Keep these updated when a feature ships or a decision changes — governance and cadence in [`../CONVENTIONS.md`](../CONVENTIONS.md) §5.
